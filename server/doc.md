## Функциональные возможности

### Команды

1. Возможность создать должность с определённой ставкой <- (<br/>
    - Название должности,<br/>
    - Ставка<br/>
)
2. Возможность добавить несколько должностей сотруднику с фиксированными ставками <- (<br/>
    - Список идентификаторов должностей, <br/>
    - идентификатор сотрудника<br/>
)
3. Возможность указать совместительство сотрудника <- (<br/>
    - идентификатор сотрудника, <br/>
    - является ли совместителем<br/>
)
4. Возможность отправить сотрудника в отпуск на определенное время <- (<br/>
    - идентификатор сотрудника, <br/>
    - время начала,<br/>
    - время окончания<br/>
)
5. Возможность отправить сотрудника на больничный <- (<br/>
    - идентификатор сотрудника<br/>
)
6. Возможность вернуть сотрудника с больничного <- (<br/>
    - идентификатор сотрудника<br/>
)

### Запросы

1. Получение профиля сотрудника по идентификатору -> (<br/> 
    - Список должностей сотрудника,<br/>
    - В отпуске ли сотрудник,<br/>
    - На больничном ли сотрудник,<br/>
    - Является сотрудник совместителем<br/>
)
2. Получение истории больничных сотрудника -> (<br/>
    - Список больничных сотрудника<br/>
)
3. Получение истории отпусков -> (<br/>
    - Список отпусков сотрудника<br/>
)
4. Получение списка должностей -> (<br/>
    - Список должностей которые можно добавить сотруднику<br/>
)

## Бизнес-сущности

### Должность

| Поле | Описание | Ограничение | 
| ---  | ---      | ---         |
| Название (name) | Название должности | Строка, уникальная |
| Ставка (rate) | Зарплата в рублях | число, не меньше минимума |

### Больничный

| Поле | Описание | Ограничение | 
| ---  | ---      | ---         |
| Начат в (started_at) | Время начала больничного | не может быть больше настоящего времени |
| Окончен в (ended_at) | Время окончания больничного | не может быть меньше времени начала больничного, не обязательно |
| Активный? (is_active) | Флаг активности больничного | true только в случае если указано время окончания | 
| Сотрудник (employee_id) | Ссылка на сущность сотрудника | идентификатор |

### Отпуск

| Поле | Описание | Ограничение | 
| ---  | ---      | ---         |
| Начнется в (starting_at) | Время начала отпуска | - |
| Окончится в (ending_at) | Время окончания отпуска | не может быть меньше времени начала отпуска |

### Совместительство

| Поле | Описание | Ограничение | 
| ---  | ---      | ---         |
| Сотрудник (employee_id) | Ссылка на сущность сотрудника | идентификатор |
| Является ли совместителем (is_part_time) | Является ли сотрудник совместителем | булевое значение |
